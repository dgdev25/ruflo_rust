# Wave 3 Entry Criteria

Updated: 2026-08-07

Wave 3 capabilities may move to `supported` only when the release manifest records all Wave 2 evidence plus the specific migration and RVF contracts introduced by the promoted integrations, and `CapabilityManifest::validate_release(3)` passes.

- Named consumer fixtures for every newly promoted Wave 3 contract.
- Security coverage for the exposed boundary.
- Native platform evidence from checked-in workflow and smoke verification.
- Migration tests and RVF interoperability tests for every persisted or exchanged format.
- Supply-chain review evidence for the release candidate.
- ADR records for each long-lived Wave 3 integration.
